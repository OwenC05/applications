# Verification contract: researched applications and supervised browser release

Companion: `prd-researched-applications.md`; planning only. Tests use synthetic data, isolated temporary SQLite/Chroma and a local fake ATS. No reading actual `.env`/`.data`, live paid calls, downloads or real employer submissions authorized by this plan. Existing68Python/73Node evidence is a baseline, not proof of these features.

## A. Unit and contract gates

1. **Domain/parity:** pending/confirmed/rejected proposals, immutable correction provenance, interview resume/skip, profile/application isolation, stable question IDs, exact review history, outcome/feedback becoming history or pending proposals only, typed PII outside dense story retrieval, legacy labels and revision vectors. UI preferences must not retire fact indexes; changed fact/question/source must invalidate all dependent packets/ledgers/reviews/grants. Migration dry-run/corrupt schema/repeated IDs/profile collisions/interrupted commit leaves original byte hash unchanged; no automatic profile merge or silently upgraded research/history.
2. **Evidence:** per-question retrieval only confirmed versions; employer filters owner+application+run precede dense AND BM25 ranking. Cross-application same-company source cannot leak unless explicitly imported as a new scoped source. Missing index branch/model mismatch fails closed. Query compilation≤128tokens, bounded variants preserve negation and original question; truncation/limits visible; character spans use Unicode code points. Corrected “10%” fact cannot cite obsolete source as proof of “40%.”
3. **Research:** fetched bytes vs rendered DOM vs user-provided vs legacy text have distinct provenance. Company and exact-vacancy identities, closed-role state, seven-day freshness, redirects, parser bounds and source hash checks. Rubric separates sourced claims/inferences. Model refusal/malformed/extra schema fields do not run tools or yield complete research.
4. **Grounding:** factual spans fully covered by exact-text ledger; citations valid but “contributed”→“led”,10→40,not-Python→Python,finance exposure→deal ownership remain unsupported. Assessor cannot promote proposals. All question IDs/limits exact; missing required answers block review. Rewrites freshly assessed; edit-reassess≤1call and never changes text. Style-only feedback advisory. No-key/no-consent produces zero cloud calls.
5. **Jobs/costs:** monotonic fences, stage idempotency, separate captured revisions; all canonical writes and manifest publication fenced. Concurrent reservations cannot exceed configured token/call budget. Unknown price visibly unknown. Provider SDK auto-retry disabled. Cancellation/consent revoked between calls stops subsequent call. Prepared ambiguity retains reservation, no automatic retry; explicit warned retry creates distinct attempt.
6. **Browser contracts:** canonical serialization/hash stable; semantic field/options/file/account/destination changes invalidate grants, not arbitrary explicitly allowlisted CSRF rotation. Hidden applicant-affecting defaults are hashed; unknown fields/opaque encodings stop. Byte-identical multipart/raw HTTP is not required. Fill grant distinct from submit, expiry/one-use/profile scope. No grant from model text. Explicit typed sensitive values remain auditable; demographics/eligibility never inferred.

## B. Integration, recovery and security gates

- Real pinned embedding/reranker + ChromaHTTP + BM25 against synthetic data: per-question dual corpus filters, deterministic fusion, same-generation reads, eligible-version recheck. Preserve dense-only/BM25 baselines for eval, not production fallback.
- Kill worker before reservation, after prepared, during send, after provider acceptance, after response and before commit. Only provably unsent can replay; completed reused idempotently; ambiguous pauses. Slow old worker cannot publish after new fence. No global transaction held during network/model waits; UI status/cancel and independent profile read remain responsive.
- S2/S4 concurrency matrix: restart API recovery while a live leased build has staged dense/sparse artifacts; those artifacts survive. Expire/reclaim a job while the old worker continues; old publication fails and late artifacts remain discoverable for eventual cleanup, never mistaken for new work. Block tokenizer/model loading and assert status/cancel respond without waiting for inference or broad file/SQLite locks. Fail a rebuild with a changed chunker and assert the previous eligible generation's canonical chunk set, dense index and sparse index remain intact; independently mutate/delete a fact and prove retained old artifacts do not bypass eligibility. Resume an old cleanup ticket after a newer generation publishes; newer generation and associations survive. After producer quiescence, abandoned and late artifacts disappear and cleanup completes. Intent exists before external artifact creation; generation names are never reused between fences.
- Kill indexing after dense, after sparse, before/after publication; never mixed generation. Cancel/delete during extraction/embedding/support/fill: tombstones suppress late writes; new derivatives cannot survive deletion. Upload intent recovery distinguishes abandoned blob from active writer. Cleanup ticket stays pending while Chroma/browser/OS file removal fails; restart completes without resurrection.
- Restore consistent SQLite+blobs into empty instance, validate counts/hashes/foreign references, rebuild derived generations; cloud disabled, all browser grants/tokens invalid. Original instance/legacy backup unchanged. Deletion/export disclosures list provider/backups/local downloads outside managed cleanup.
- SSRF matrix: suffix/userinfo/encodedIP/IPv6/localhost/metadata, publicDNS→privateconnect, rebinding, redirects, redirectloop, oversized chunked/compressed bodies, slowloris, contenttype/PDF bombs. Anonymous renderer subresources, popup, JSfetch, WebSocket, serviceworker/download cannot bypass network policy. Network-deny fixtures prove denial, not only mocked URL validation. Static-only fail-closed if containment unavailable.
- Prompt injection in web/PDF/ATS content attempts exfiltration, new host, confirmation, shell command or submit: broker denies independently of model response. Public-research payload captures contain zero personal facts/cookies. Cloud drafting sees only selected approved spans. Content canaries never appear in default logs/errors/metrics; keys never appear in images/exports.
- API Host/Origin/CSRF/session scope, loopback binding and local malicious webpage probes. Companion pairing token replay/expiry/wrongorigin/wrongaccount rejected; no open DevTools/noVNC port; exclusive dedicated browser profile and private state permissions. Test logged-out and session-expired states.

## C. Browser end-to-end gates

**A workflow:** create synthetic tech/finance profiles → deliberate import → preview/confirm → resumable interview → exact role/questions → fixture original-source research → evidence explanations/gaps → async bounded drafting → inspector → factual edit blocks review → explicit confirmation/reassessment → exact review/export → restart/delete. Keyboard/mobile and delayed profile-A response after switching to B cannot cross-render.

**B fake Greenhouse adapter:** standard single-step and conditional multi-step fixtures, international names, Unicode limits, select/radio/checkbox/file/repeatable widgets. Fake-ATS receiver records every network transmission; nothing personal transmitted before exact fill grant. Before-forward semantic validation covers all applicant-bearing methods/channels: query/navigation/beacon/autosave/upload/intermediate transition. On the same approved origin/path, changed salary, an added demographic field, extra query/body data, altered uploaded bytes, delayed autosave after grant expiry/revocation and unsupported/opaque encoding must be denied: assert **zero rejected-data receipt at the receiver**, not just a local warning. A legitimate exact-approved partial autosave succeeds. Check owner/active operation/account/vacancy/step changes and explicit transport-only allowlist; page JS restoring DOM after malicious transmission cannot evade the gate. Account/destination/attachment changes stop. Discovery of new question feeds drafting; stale field map not applied. Hidden fields, duplicate labels, deceptive Submit/Next including Continue that actually finalizes, iframes, custom unsupported controls and unexpected popups require manual handoff. Login/MFA/CAPTCHA and assessments are never bypassed. No-full-page-to-model canary assertions. Known final endpoint blocked under fill-only consent regardless of button/JS/autosave; unapprovedorigins/serviceworkers/WebSockets blocked. Immutable approved upload artifact prevents TOCTOU, and approving CV does not auto-confirm its facts. Multi-step pages unreachable without writing show explicit limited initial fill consent.

**C fake submission:** user approval cancelled/expired/reused, draft edit, new required field, file altered after preview, account switched, destination redirected all prevent click. Kill before prepared/after prepared/after click/after remote acceptance/before receipt commit. At most one automatic final action per grant; unknown blocks retry. HTTP200/error/intermediate navigation never treated as confirmation. Explicit confirmation/reference yields receipt-confirmed; manual report stays user-reported. Receipt retention minimal and deletion verified. Test anti-double-click/concurrent tabs, page-XHR retries, final-request interception/semantic comparison and restart reconciliation; no exactly-once external guarantee. Unrecognized transport encoding/hidden application fields switch to manual submission. Every outbound request confined to test hosts; network guard makes real ATS submission impossible in suite.

## D. Quality release gates (freeze before tuning)

Dataset: at least60 English questions,30tech/30finance;≥15unanswerable and≥10negation/contradiction/distractor cases (categories may overlap). Include observed snake/software negation failure unchanged as regression. Freeze labels/hashes and stratified train/tune/held-out split before tuning;≥30held-out, balanced sectors with≥8unanswerables and≥5adversarial. Publish counts, every failure and uncertainty; do not silently move cases between sets.

- Held-out answerable Recall@8≥0.85; hybrid no>0.03absolute regression vs best single retriever; report nDCG/MRR and no claimed hybrid advantage unless measured.
- End-to-end semantic unanswerable abstention≥0.90 (retriever returning hits is not abstention). Negation regression must either select genuinely supporting evidence or abstain, never support the distractor. Any critical invented qualification/result blocks release even if aggregate passes.
- Deterministic citation/ownership/revision integrity100% across suite. Support assessment report precision/recall/confusion counts against human span labels, including unsupported/contradictory cases; minimum supported-claim precision0.95 on≥40audited factual claims, and zero critical invented qualification/result. This is a measured gate, not guarantee of future truth.
- Two reviewers independently blind-compare12answers (6tech/6finance) to frozen existing lexical baseline for factuality, role/company specificity, authenticity and completeness. At least8/12 preferred or tied overall after adjudication, no critical false claim; disclose disagreement and small sample. Mock provider responses cannot pass editorial-quality gate. Live model evaluation requires separate explicit opt-in/key/budget; if absent release remains evaluation-blocked.
- CPU benchmark1,000chunks,documented hardware/model versions,cold/warm latency,p50/p95,peakRAM,buildtime; target warm retrieval p95≤5s excluding cloud. If missed, tune without hurting quality or document higher hardware requirement before release; no silent target rewrite.
